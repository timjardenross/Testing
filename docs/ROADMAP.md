# Roadmap

## Before operational activation

Complete source-plan activation gates with the accountable owner: confirm delegates / after-hours reachability, validated Business Centre register, communication distribution lists, enterprise BC Manual pathways, classification, approval and the team tabletop. Verify Pages restrictions on the actual GHES version, supported managed browsers and restore drill. Resolve or explicitly accept exercise findings through the source governance process.

## Next technical increments

Prioritise event-level persistence / pagination if data volume grows, stronger draft autosave recovery, richer field-specific change summaries, operator-tested print layouts, automated multi-browser coverage and extended assistive-technology testing. A local import reconciliation preview could compare entire conflicting events before replacement. Each enhancement must preserve deterministic evidence and no silent overwrites.

## Approved shared data

Introduce a server-backed Repository adapter with conditional revisions, approved identity, server authorisation, validated commands and authoritative audit storage. Migrate browser exports with preview and traceable import records. Preserve completed version snapshots and rules versions; do not re-evaluate history. Define multi-user conflict ownership before enabling simultaneous editing.

## Additional packs

Extract a pack interface and discriminated schemas when a second approved operating model exists. Keep hazard prompts / actions / authority separate from shared evaluation and repository concerns. Technology, supplier, workforce, property and telecommunications packs need their own approved thresholds and acceptance scenarios; none is inferred from climate rules.
