# Changelog

## 1.0.0-tabletop.1 — 2026-09-15

Initial self-contained application based on Operational Plan v0.6 DRAFT and Outlook v1.0 Approved. Adds deterministic T0–T4 assessment, human decisions, local version history, live actions / communications / escalation, recovery, exposure register, readiness, backup / restore and static packaging.

Validation fixes include separate form labels, full expected impact / recovery schema keys, stale-tab write rejection, recovery closure safeguards, immutable centre / operation snapshots, and UTC handling for date-time controls.

This software release number does not change the source plan's draft status or imply approval for operational activation.
